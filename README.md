# USDT Portfolio Tracker

> **Made by Mostakim Alam**

A web-based dashboard for tracking USDT balances across multi-chain EVM networks (Ethereum, BNB Chain, and Polygon) as well as off-chain/manual wallet balances in real time.

---

### 🔑 Key Features
* **Multi-Chain Support:** Automatically scans and tracks USDT balances across Ethereum (ETH), BNB Chain (BSC), and Polygon (POL).
* **Manual & Off-Chain Tracking:** Allows manually adding custom balances for external exchanges or offline wallets.
* **Network Filtering:** Filter portfolio view by specific chains (Ethereum, BNB Chain, or Polygon).
* **Auto-Refresh Interval:** Configurable real-time auto-refresh settings (30s, 1m, 5m, or disabled).
* **Privacy-Focused:** Local client-side tracking using public wallet addresses.

---

### 🚀 Usage
1. Open the web application in your browser.
2. Click on the **Settings & Accounts** menu.
3. Add your target EVM wallet addresses and any manual/off-chain balances.
4. Set your preferred auto-refresh interval and network filters to monitor your total USDT portfolio in real time.
